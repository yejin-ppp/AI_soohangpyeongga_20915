# 2026 고2 수학 모의고사 오답 개념진단 클리닉 (2022 개정 교육과정 연계)

2026학년도 고등학교 2학년 전국연합학력평가(3월·6월·9월)의 **오답률 상위 15위 문항(총 45문항)**을 기반으로, 학생이 막힌 문제 해결 단계를 '예/아니오' 인터뷰로 역추적하여 **2022 개정 수학과 교육과정 성취기준**의 결손 지점을 정밀 진단하고 맞춤 처방전을 제시하는 인터랙티브 웹 애플리케이션입니다.

---

## 📌 주요 핵심 기능

1. **전국연합학력평가 3·6·9월 오답률 Top 15 (총 45문항) 전수 진단**
   - **3월 모의고사 (서울시교육청)**: 공통수학1 전 범위 & 공통수학2 전 범위 (행렬, 도형의 방정식, 집합과 명제, 함수 등)
   - **6월 모의고사 (부산시교육청)**: 대수 전 범위 (지수함수와 로그함수, 삼각함수)
   - **9월 모의고사 (인천시교육청)**: 대수 전 범위 & 미적분Ⅰ (함수의 극한과 연속, 미분계수와 도함수의 활용)

2. **해설지 사고 알고리즘 기반 3~4단계 순차 질문 (Q1 ~ Q4)**
   - 문제 풀이의 첫 단추부터 최종 계산까지 논리적 흐름에 맞춘 진단 질문 제시
   - **'예'**를 누르면 다음 사고 단계(Step)로 자동 전진
   - 모든 질문에 '예'를 선택하면 **"개념 결손 없음 (계산 실수 또는 시간 부족 유형)"**으로 판정

3. **즉시 결손 포착 & 2022 개정 성취기준 1:1 매핑**
   - 학생이 특정 단계(예: Q2)에서 **'아니오'**를 클릭하면 즉시 진단 종료
   - 교육부 고시 제2022-33호 [별책 8] 수학과 교육과정 공식 성취기준 코드(예: `[12미적Ⅰ-02-08]`, `[12대수02-01]`, `[10공수1-04-01]`) 출력
   - 막힌 원인을 분석한 **부족한 핵심 개념 정밀 분석** 및 **맞춤형 클리닉 처방전** 제공

4. **최종 진단 리포트 카드 및 인쇄/PDF 저장**
   - 오답 문항 요약 (회차, 문항 번호, 단원, 오답률 순위, 배점)
   - 막힌 풀이 단계(Step) 및 질문 원문
   - 2022 개정 교육과정 성취기준 코드, 명칭, 소속 영역
   - 학생의 단계별 진단 인터뷰 상세 로그 (예/아니오 히스토리)
   - '다른 문항 진단하기' 원클릭 초기화 및 '리포트 인쇄/저장' 기능

5. **수식 렌더링 최적화 (KaTeX Engine)**
   - 수식 기호($f(x)$, $\sin\theta$, $\alpha$, $\beta$, 행렬 등)의 깨짐 없는 미려한 수학 서식 출력

## 🌐 GitHub 업로드 및 GitHub Pages 배포 안내

### 1. Git 저장소 초기화 및 커밋
프로젝트 폴더 터미널에서 아래 명령어를 순서대로 실행합니다:

```bash
git init
git add .
git commit -m "feat: 2026 고2 수학 모의고사 45문항 2022 개정 교육과정 진단 클리닉 구현"
```

### 2. 원격 GitHub 레포지토리 연결 및 푸시
GitHub에서 새 Repository(예: `math-diagnosis-clinic`)를 생성한 후:

```bash
git remote add origin https://github.com/사용자아이디/레포지토리이름.git
git branch -M main
git push -u origin main
```

### 3. GitHub Pages로 무료 웹 호스팅 켜기
1. GitHub 레포지토리 페이지 상단의 **[Settings]** 탭 클릭
2. 좌측 메뉴의 **[Pages]** 클릭
3. **Build and deployment > Branch** 항목에서 `main` 브랜치와 `/ (root)` 폴더 선택 후 **[Save]** 클릭
4. 약 1분 후 제공되는 URL(`https://사용자아이디.github.io/레포지토리이름/`)로 접속하면 전 세계 어디서든 스마트폰과 PC로 접속 가능합니다!
